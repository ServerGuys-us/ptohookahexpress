# PRODUCT.md

## Product Brief

**Product:** Hookah Lounge Booking Landing Page
**Brand:** PTO Mobile Experience
**URL:** ptomobile.com (parent brand)

---

## Purpose

A single-page booking site for PTO Mobile's Hookah Lounge offering. The page should capture reservations/inquiries with a clear CTA flow, communicate the vibe, and convert visitors into booked guests.

---

## Target Audience

- Adults 21+ in the greater Houston metro
- Birthday/bachelorette party planners
- Corporate event organizers
- Nightlife seekers looking for upscale lounge experiences

---

## Core User Journey

1. Land on hero → feel the brand, understand the offering
2. See what's included (amenities, packages)
3. Check availability / pick a date
4. Submit booking request → confirmation message

---

## Key Content Sections

1. **Hero** — Headline, subhead, primary CTA ("Reserve Your Night")
2. **About the Experience** — What the hookah lounge is, atmosphere, vibe
3. **Packages / Pricing** — 2–3 tiers (e.g., Base, VIP, Private Buy-Out)
4. **Amenities** — Hookah flavors, bottle service, seating, music, etc.
5. **Gallery** — Placeholder grid (imagery TBD)
6. **Booking Form** — Date, time, guest count, occasion, contact info
7. **FAQ** — Common questions (age requirement, deposits, cancellation)
8. **Footer** — Contact, social links, address, copyright

---

## Booking Form Fields

- Full name (required)
- Email (required)
- Phone (required)
- Event date (date picker, required)
- Approximate start time (select, required)
- Guest count (number, required)
- Occasion (select: Birthday / Bachelorette / Corporate / Date Night / Other)
- Package interest (select: Base / VIP / Private Buy-Out)
- Special requests (textarea, optional)
- Submit → confirmation message ("We'll confirm within 2 hours")

---

## Business Rules

- Minimum group size: 2
- Maximum capacity: 20 (shared with party bus)
- Response SLA: 2 hours during operating hours
- Operating hours: Mon–Sun 6PM – 2AM
- Deposit required to confirm booking

---

## Out of Scope (v1)

- Payment processing
- Real-time availability calendar
- User accounts / login
- Admin dashboard
